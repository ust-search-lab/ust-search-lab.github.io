# 사진첩과 공지사항 연결

[관리자 화면](https://ust-search-lab.github.io/admin/)에 GitHub로 로그인하면 외부에서도 사진첩과 공지사항을 관리할 수 있습니다.

## 1. 사진첩 만들기

1. **자료 관리 → 사진첩**에서 사진첩 목록에 항목을 추가합니다.
2. 고유 ID, 한·영 제목과 소개, 수정일을 입력합니다. ID는 `imewg-2026-canada`처럼 영문 소문자·숫자·하이픈을 사용하고 게시 후 유지합니다.
3. **사진** 목록에 파일과 한·영 대체 텍스트를 입력합니다. 기존 파일을 선택하거나 **Insert from URL**로 이미 게시된 사진의 원본 주소를 입력해도 됩니다.
4. 사진 순서를 정합니다. 첫 번째 사진이 Resources 목록의 표지입니다. 세로 사진은 공지사항에서 표시할 너비를 **세로 사진용 너비**로 선택할 수 있습니다.
5. 게시합니다. 자동 배포가 완료되면 Resources의 **사진첩**에 표시됩니다.

대체 텍스트는 접근성을 위한 설명이며, 사진 아래에 보이는 캡션으로 표시되지 않습니다. 업로드는 사진당 20 MiB까지 지원합니다.

## 2. 공지사항에 연결하기

1. 관리자 화면의 **공지사항 · NEWS**에서 기존 글을 열거나 새 글을 만듭니다.
2. 제목, 언어, 게시일, 요약과 본문을 입력합니다. 같은 소식의 한·영 글은 같은 **연결 ID**를 사용합니다.
3. **연결할 사진첩**에서 먼저 게시한 사진첩을 검색해 선택합니다.
4. **사진첩 표시 방식**을 선택합니다.
   - **사진과 사진첩 링크:** 본문 아래에 사진첩의 사진을 순서대로 표시하고 사진첩 링크를 붙입니다.
   - **사진첩 링크만:** 사진첩으로 이동하는 링크만 표시합니다.
5. 게시합니다. 한국어와 영어 글에서 각각 같은 사진첩을 선택하면 두 글 모두 동일한 원본을 사용합니다.

사진첩 페이지에도 해당 언어의 관련 공지사항 링크가 자동으로 표시됩니다. 새 공지사항의 주소는 언어, 게시일의 한국시간 날짜, 연결 ID로 생성됩니다. 기존 글의 주소는 유지됩니다. 본문 편집은 기존 표와 삽입 코드를 유지하도록 Markdown 모드를 사용합니다.

## 3. 개별 사진만 다른 글에 사용하기

사진첩 페이지에서 원하는 사진의 **사진 주소 복사**를 누릅니다. 공지사항 본문의 이미지 삽입에서 그 주소를 사용하거나 다음 Markdown 형식으로 입력합니다.

```markdown
![사진 내용을 설명하는 대체 텍스트](복사한-사진-주소)
```

파일을 다시 업로드할 필요가 없습니다. 자동 연결된 사진과 본문의 사진이 겹치면 표시 방식을 **사진첩 링크만**으로 설정합니다.

## 4. 수정과 삭제

사진첩의 사진, 순서 또는 표시 너비를 바꾸면 연결된 공지사항에도 다음 배포에서 반영됩니다. 본문에 원본 주소를 직접 삽입한 사진은 해당 주소를 따로 관리합니다.

공지사항이 연결된 사진첩을 삭제하려면 먼저 각 글의 **연결할 사진첩**을 비우거나 다른 사진첩으로 변경해 게시합니다. 연결이 남아 있는 사진첩을 삭제하면 빌드 검사가 이를 알리고 배포를 중단합니다. 원본 파일은 다른 글에서도 사용할 수 있으므로 사용 중인 링크를 확인한 뒤 삭제합니다.

사진첩 데이터는 `_data/gallery.yaml`, 공지사항은 `_posts/`, 새로 업로드한 파일은 `downloads/materials/`에 저장됩니다. 기존 IMEWG 사진은 `images/news/imewg-2026-canada/`의 원본을 그대로 재사용합니다.

구현 참고: [Decap 관계 선택 필드](https://decapcms.org/docs/widgets/relation/), [폴더형 콘텐츠 관리](https://decapcms.org/docs/collection-folder/).
